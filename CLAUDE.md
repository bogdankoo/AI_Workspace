# AI Workspace

## О проекте

Веб-приложение для работы с ИИ: рабочие пространства, запросы, история.
Учебный проект по роадмапу. Цель: работать с агентом осознанно и проверять результат.

## Стек

- react, nextJS, TypeScript (strict), npm, npx
- Не добавлять зависимости без моего согласия

## Команды

- Запуск: `npm run dev`
- Проверка: `npm run lint`, `npm run typecheck`, `npm run build`

## Структура

- `src/` код приложения
- `docs/` концепция, решения (ADR)

## Правила кода

- Строгий TypeScript, без `any`
- Небольшие компоненты, понятные имена
- Комментарии только там, где неочевидно «почему»

## Как работать

1. Сначала изучи код и предложи план, потом меняй файлы.
2. Делай только то, что просили, без лишних правок.
3. Не считай задачу готовой, пока не прошли lint, typecheck и build.
4. Не трогай `.env`, не выводи ключи и секреты.
5. Перед установкой зависимостей и необратимыми действиями спрашивай.

## Готово, когда

- Проверки проходят, приложение запускается, изменение показано мне и объяснено.

## Роадмап

Рядом лежит мой личный роадмап обучения — `Bogdan-roadmap.rtf` («AI-Native Web & Experience Engineer»). Пять этапов: AI Operator Bootcamp → AI Engineering Foundation → Web & Experience Foundations → Advanced Web & AI Experience Engineering → Independent Engineering.

- Связывай текущую задачу с этапом роадмапа и подсказывай, как она двигает к цели.
- Проактивно давай советы и предлагай следующий шаг по роадмапу, чтобы я проходил его быстрее.
- Видишь пробел в понимании — коротко объясняй и показывай, как это закрывает текущий этап.
- Приоритет: быстрое и осознанное продвижение по роадмапу, а не только «сделать задачу».
