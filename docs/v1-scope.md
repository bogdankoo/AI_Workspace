# AI Workspace — концепция и объём v1

## Что это

Веб-приложение для взаимодействия с ИИ: рабочие пространства, запросы, история.
На первом этапе — каркас без реальной модели: ответы заглушкой, чтобы проверить
сценарий целиком и только потом подключать LLM.

## Сценарий v1

1. Пользователь открывает приложение и видит список воркспейсов.
2. Создаёт новый воркспейс или выбирает существующий.
3. Пишет запрос в поле ввода и отправляет.
4. Запрос и ответ появляются в истории воркспейса.
5. Можно переключиться на другой воркспейс — история у каждого своя.

## Входит в v1

- Список воркспейсов с созданием и переключением.
- Поле ввода запроса с отправкой по Enter.
- История сообщений внутри воркспейса (роли пользователь/ассистент).
- Ответ-заглушка ассистента с индикатором ожидания.
- Состояние хранится в памяти приложения (без БД и API).

## Сознательно отложено

- Реальная LLM и стриминг ответов (Stage 2 / Stage 4).
- Сохранение истории между перезагрузками (localStorage или БД).
- Аутентификация и мультипользовательский режим.
- Переименование и удаление воркспейсов.
- Markdown-рендеринг ответов.
- Подтверждения и отмена действий ИИ (human-in-the-loop UX, Stage 4).

## Критерии готовности v1

- `npm run lint`, `npm run typecheck`, `npm run build` проходят.
- `npm run dev` поднимает приложение, сценарий из раздела выше выполняется целиком.
