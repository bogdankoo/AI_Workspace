# AI Workspace

Веб-приложение для работы с ИИ: рабочие пространства, запросы, история.
Учебный проект по роадмапу «AI-Native Web & Experience Engineer».

## Стек

- Next.js (App Router) + React + TypeScript (strict)
- Tailwind CSS
- ESLint

## Команды

```bash
npm run dev        # запуск в режиме разработки (http://localhost:3000)
npm run lint       # ESLint
npm run typecheck  # tsc --noEmit
npm run build      # production-сборка
npm run start      # запуск production-сборки
```

## Структура

- `src/app/` — маршруты и layout (App Router)
- `src/components/` — компоненты интерфейса
- `src/lib/` — типы и заглушка ассистента
- `docs/` — концепция и объём первой версии
